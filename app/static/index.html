💬 微信推送 · 配置说明
使用"小毛机器人"（maobot）推送：
1️⃣ 在微信里添加机器人好友
2️⃣ 向机器人查询你的 用户ID 和 API Key（在机器人后台/对话指令中获取）
3️⃣ 到"📇 接收者"页为每个人填写：微信接收人=用户ID、微信Key=API Key
默认服务器地址：https://api.maobot.org/send_message（已内置，接收者可单独覆盖）
