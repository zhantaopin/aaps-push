# AAPS 推送服务

为 **AAPS（AndroidAPS）/ 人工胰腺闭环** 用户打造的自托管血糖监控与预警推送服务。

服务端持续轮询你的 Nightscout 站点，按你配置的**预警任务**（血糖、增量、IOB、COB、基础率、药量、泵状态、手表电量等 17 种条件自由组合）判断异常，并通过**微信（小毛机器人）**或 **Bark（iOS）** 推送到你和家人手机。

- 支持多个 Nightscout 数据源（可命名、可分组），任务可绑定指定数据源
- 增量算法采用 AAPS 官方口径（5/15/30 分钟三档窗口平均）
- Web 管理台（响应式，手机可用），全中文配置界面
- 多实例部署时通过心跳自动选主，避免重复推送

## 功能特性

| 模块 | 说明 |
|---|---|
| 多数据源 | 添加多个 Nightscout 站点（地址 + token），各自独立采集与增量计算 |
| 预警任务 | 17 种条件：血糖绝对值 / delta、短、长增量 / IOB（总、大剂量、基础率）/ COB / 基础率 / 剩余药量 / 泵状态 / 血糖、泵延迟 / 最终预测BG / 手表电量、充电状态、30分钟掉电 等，自由组合（与/或） |
| 一键任务模板 | 内置低血糖、高血糖、快速下降、低电量等常用预警模板 |
| 接收者 | 每位接收者独立配置微信（用户ID + API Key）和/或 Bark（Key + 级别）；可建分组，任务按"分组 + 个人"多选分发 |
| 提醒频率 | 一次性 / 循环提醒（间隔可设）/ 恢复自动报平安 |
| 模拟判定 | 不发真实推送即可预演任务当前是否命中 |
| 事件日志 | 每次触发记录时间、命中原因与推送结果 |
| 多实例 | 云端 + 本地同时跑也不重复推送（Nightscout 心跳选主） |

## 安装与部署

### 方式一：Docker 一键部署（推荐）

```bash
git clone https://github.com/<你的用户名>/aaps-push.git
cd aaps-push
./deploy.sh                          # 默认端口 8300，默认密码 admin
# 或自定义：
PORT=9000 ADMIN_PASSWORD=你的强密码 ./deploy.sh
```

脚本会生成 `.env`、构建镜像并后台启动。

### 方式二：手动 Python 运行

```bash
pip install -r requirements.txt
DATA_DIR=./data ADMIN_PASSWORD=你的强密码 python3 -m app.main --port 8300
```

### 验证

浏览器打开 `http://<服务器IP>:8300`，输入管理密码登录。
健康检查：`curl http://127.0.0.1:8300/api/health`

## 启动 / 停止 / 重启 / 日志

```bash
docker compose up -d        # 启动（首次会自动构建）
docker compose stop         # 停止（数据保留）
docker compose restart      # 重启
docker compose down         # 停止并移除容器（data/ 配置数据保留）
docker compose logs -f      # 查看实时日志
```

## 升级与卸载

**升级**（配置数据都在 `data/` 目录，代码更新不影响）：

```bash
git pull
docker compose up -d --build
```

**卸载**：

```bash
# 1.（可选）先在管理台导出配置 JSON 备份
# 2. 停止并删除
docker compose down --rmi all
# 3. 删除项目目录（连带删除 data/ 下的全部配置与数据库）
cd .. && rm -rf aaps-push
```

> `data/` 目录包含 SQLite 数据库（全部任务/接收者配置）和心跳记录，**删除前请确认已导出备份**。

## 使用指南

### 1. 配置 Nightscout 数据源

**设置 → 数据源 → 添加**，填入：

| 字段 | 说明 |
|---|---|
| 名称 | 自定义（如"默认"、"爸妈的"），任务里按名称选择 |
| 地址 | Nightscout 站点 URL，如 `https://xxx.herokuapp.com` 或自建地址 |
| Token | NS 的 `token`（在 NS 管理后台创建，需 `read` 权限）；站点未开鉴权可留空 |
| 分组 | 可选，仅用于数据源列表整理 |

保存后等一个采集周期（默认 60 秒），状态卡出现血糖数据即成功。

### 2. 配置接收者（推送目标）

**接收者 → 新建接收者**，每个接收者可勾选一个或多个渠道：

**微信（小毛机器人）：**

| 字段 | 说明 | 从哪获取 |
|---|---|---|
| 微信接收人 | 消息发给谁 | 关注小毛机器人后，机器人后台/对话里查看；**个人私聊填你的微信用户ID；发群填群ID（形如 `xxxx@chatroom`）** |
| 微信 Key | 机器人 API Key | 小毛机器人后台的 API Key 页面 |
| 微信地址 | 推送接口 | 默认 `https://api.maobot.org/send_message`，一般不用改 |

> 注意：小毛机器人**私聊默认只允许发给本人**；要发给家人或群，需把机器人拉进群并使用群ID，或按机器人后台的授权说明开通。

**Bark（iOS）：**

| 字段 | 说明 | 从哪获取 |
|---|---|---|
| Bark Key | 设备推送密钥 | App Store 安装 [Bark](https://apps.apple.com/app/bark/id1401237055)，打开 App 首页复制的 URL 中 `https://api.day.app/` 后面那段 |
| Bark 地址 | 推送服务器 | 默认 `https://api.day.app`，自建 Bark 服务器则填自建地址 |
| 通知级别 | 按成员取最高级别生效 | `critical`（持续响铃）> `timeSensitive`（时效性）> `active`（默认亮屏响声）> `passive`（静默，仅列表） |

每个接收者卡片有 **测试** 按钮，只测你勾选的渠道。

### 3. 接收者分组

**接收者分组 → 新建分组**，勾选成员（如"全家"）。任务里可以同时勾选**分组 + 个人**（去重后最多 10 项），推送时按每个接收者自己的渠道配置分发。

### 4. 创建预警任务

**任务 → 新建任务**（或从模板一键创建）：

| 字段 | 说明 |
|---|---|
| 名称 | 自定义（任务按分类折叠展示，可拖动排序） |
| 数据源 | 该任务绑定哪个 NS 源（留空用第一个） |
| 提醒频率 | 一次性 / 循环（间隔分钟，触发后进入冷却）/ 恢复后再次提醒 |
| 触发条件 | 17 种条件自由组合，每条有中文说明；支持"与/或"逻辑 |
| 通知内容 | 推送文案，可包含占位符（自动附上当前血糖、增量等） |
| 接收者 | 分组 + 个人多选 |
| 模拟判定 | 保存前预演：显示每条条件实时取值与是否命中 |

### 5. 事件日志

首页下方实时记录每次触发的时间、命中条件与推送结果，用于校验任务是否按预期工作。

## 常见问题

**Q: 微信推送返回 403 "私聊只允许本人"？**
A: 填的不是你自己的微信用户ID，或机器人未授权私聊他人。发群请填群ID（`xxxx@chatroom`）并确认机器人已在群里。

**Q: 群里收不到消息？**
A: 三个检查：① 群ID 是否正确（机器人后台查）② 机器人是否已被拉进群 ③ 小毛后台发送日志有无拦截记录。

**Q: 增量（delta）显示 0？**
A: 窗口内只有一条血糖读数时无差值可算（刚恢复数据/刚启动属正常），等下个周期有新读数即恢复。

**Q: 云端和本地同时跑会重复推送吗？**
A: 不会。多实例通过 Nightscout 心跳自动选主，只有主实例执行规则。

**Q: 支持 Gluroo/Dexcon 等其他数据源吗？**
A: 当前仅支持 Nightscout 兼容 API（AAPS/Trio/Loop 用户均适用）。
